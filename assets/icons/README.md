# Icons

From [Lucide](https://lucide.dev) 1.55.0 (`lucide-static` on npm), unchanged.
They are compiled into the app by `src/gui/icon.rs`; see `LICENSE` here for
their terms (ISC, and MIT for the icons derived from Feather).

To add one, copy its file from `lucide-static/icons/` at the same version
and add it to the `Icon` enum.
